# 项目开发沿革

本文记录 SuperMimic 独立复现工程在 2026-10-26 至 2026-10-27 的实现过程与检查证据，供公开仓库读者理解当前代码的来历。它不是论文复现成绩报告；运行目录、日志与检查点属于本地开发证据，未随公开文档发布。

## 项目边界与参考来源

本项目以用户提供的 SuperMimic 论文为方法依据，以 mjlab 为仿真底座，采用独立模块结构逐步实现。第三方仓库 [CuboiLeo/SuperMimic-Reproduced](https://github.com/CuboiLeo/SuperMimic-Reproduced) 用于接口和实现参考；核对时使用固定版本 `d9be385b3eeb13a638fb33fb200d3bfd9be9839f`。它不是论文作者官方代码，也不构成本项目正确性证明。LAFAN1 G1 动作源固定到 `lvhaidong/LAFAN1_Retargeting_Dataset` revision `ce1572906efe6157840e8474d5a0d7aa87481e74`。

方法依据、实现选择和工程适配在文档中分开说明。本项目保留论文可辨认的在线仿真采集、世界模型拟合、世界模型想象及策略/价值更新关系；不把 mjlab 自带 PPO 当作 SuperMimic，也不接管第三方完整训练工程。

## 时间线

### 2026-10-26：从初始化接口扩展到最小训练闭环

- 在已有 G1 与 LAFAN1 加载基础上，按模块补齐参考状态重置、跟踪任务、经验回放、世界模型核心、可微观测/奖励输出和三阶段训练循环。
- 完成标准限定为 Mac CPU 上的小规模真实采集和训练执行：真实转移入库；8 步动力学窗口不跨 episode；世界模型、策略、critic 均更新；32 步想象期间模型与 critic 权重冻结而输入梯度仍可传回策略；损失和梯度有限。
- 最小闭环使用 2 个并行环境、40 条参考动作全部加载，但只从 `walk1_subject1` 和 `dance1_subject1` 采集；缩小 replay、batch 和每轮更新规模，保留完整网络宽度及论文的 `k=8`、`H=32` 结构。两轮 smoke 实际采集 192 条转移，并执行了世界模型、policy 和 critic 更新。
- 随后为训练准备持续记录和恢复入口：逐轮指标、转移、detached 想象 probe、原子 checkpoint、正常退出/中断保存，以及继续训练入口。固定 seed 的记录开/关短程对照中，各模型 state_dict 逐张量相同。
- 初次集成因 FK 错把 terrain 纳入身体树而在训练前失败，修复后补了检查。早期运行曾有 line-search 迭代上限提示；提高训练 profile 的 line-search 上限后，最终初始闭环运行未再出现该提示。后续开发运行仍出现 solver 迭代上限警告，详见[已知问题](known-issues.md)。

### 2026-10-27：语义修复、损失适配与 critic 输入检查

- 根据 SuperTrack 的分组 L1/初始贡献平衡思路，采用六组几何状态误差、由首次真实窗口确定并固定的归一化尺度；保留 raw MSE 基线。它是对 SuperTrack 思路的工程适配，不是 SuperMimic 论文公开指定的损失。两轮 CPU 闭环及续训一轮完成，六组首次贡献均为 1.0；这项构造性检查不代表参数梯度平衡或学习改善。
- 修复动作角色混用：明确区分策略原始动作 `policy_action` 与含探索噪声的 `executed_action`，动力学监督使用后者，平滑项和观测中的上一动作使用前者。新数据语义配置为 `clean-policy_executed-dynamics-v2`。
- 修复预处理器近同四元数旋转提前返回左端点的问题，改用 float64 时间网格及归一化最短弧插值，小角度使用 nlerp；激活 `preprocess_version=2`，旧 v1 数据保留并由 manifest 隔离。独立核对覆盖 40 条动作、441,140 帧，并与 SciPy 插值对照。
- 集中语义核对厘清了真实采集、参考时间、重置边界、奖励对齐、FK 范围、动作/观测和 checkpoint 续训含义。参考奖励使用 post-step 状态与下一参考帧；这是明确的工程约定，不宣称逐指令复原作者私有实现。
- 按已确认的接口选择给 critic 增加 4 维相对根位姿特征（相对位置 3 维及 yaw 差 1 维），输入从 784 扩至 788 维。检查覆盖坐标变换、有限差分、冻结 critic 的输入梯度、probe 帧对应和续训配置保护；不能据此断言该输入改善价值估计。
- 新损失、动作/数据修复、critic 输入各自有独立的检查记录及运行源码摘要；Git 仓库当时为 `main` 且无 commit，因此记录中的 SHA 是源码/manifest 哈希和实验标识，不是 Git commit。

## 当前实现证据如何解读

截至以上开发日期，Mac CPU 上已通过记录的短程闭环、组件/定向检查和有限续训检查。它们证明所检查路径能执行，并支持数据连续性、数值有限性、梯度可达性和参数冻结等局部结论。它们不证明策略学会了动作，不证明世界模型达到目标精度，也不证明论文结果已复现。

GPU/CUDA 路径、正式规模的并行性能、完整训练日程、正式评估划分、多随机种子效果和付费 GPU 运行均未在这些记录中验证。所有 run 都是短程 CPU 开发检查；没有按短跑回报挑选“最好结果”。
