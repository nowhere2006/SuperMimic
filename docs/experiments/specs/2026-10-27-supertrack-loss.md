# SuperTrack 思路的世界模型损失适配

用户于2026-10-27明确选择参考 SuperTrack 调整世界模型损失，并在后续训练中再判断是否调权重。本卡限定实现与本地验证，不是学习效果实验协议；无需重复索取这次修改的授权。

- 假设：用几何误差的分组 L1，并按初始误差校准固定尺度，可以使六组状态损失在初期有接近的贡献，且保留有限、非零的动力学与策略梯度。**不假设本次短检查证明回报改善。**
- 基线：修改前 `fit_world_model` 的原始71维平方差（四元数标签同半球对齐）加终止 BCE。保存 `raw_mse` 模式作对照；源码快照及 SHA 在 `.cache/change-baselines/2026-10-27-supertrack-loss/`。Git 为 main/unborn，无 commit；项目禁止擅自提交，因此沿用当前工作区并保存精确改前文件，不为创建 worktree 改写 Git 历史。
- 来源：[SuperTrack](https://theorangeduck.com/media/uploads/other_stuff/SuperTrack.pdf)，2021，PDF共13页，§3.4/Algorithm 1：分组 L1、相对四元数 log，权重使训练初期各项贡献接近。论文未给可直接复制的自动校准算法。以下六组、自动校准与终止头处理均为本项目显式适配，**不是 SuperTrack 原样复现，也改变了当前 SuperMimic 状态 MSE 的实现选择**。
- 最小变化：六组 `[dp, rotvec, dv, domega, dq, dqdot]`，沿用已定义的70维误差；每组取分量绝对值均值。首次已采样的8步真实 replay 窗口，在优化前计算各组 B×K×D 平均误差，作为固定分母；取 `max(initial_mean, 1e-6)` 防止除零，记录触底组。此数值下限不代表物理容差；首批代表性不足是已知限制。校准不多抽样、不重跑仿真。
- 损失：每步六组 `manual_weight[g] * mean(abs(error[g])) / initial_scale[g]` 相加，再对8步求和。默认额外组权重全1；未触底时初始状态损失约 `6*K`。终止 BCE 仍按 batch均值/时间求和，独立系数默认1。它不会被自动校准；当前不声称状态与 BCE 或参数梯度已经平衡。
- 校准一次后固定，禁止每个batch重校准或随resume重算；记录于event/checkpoint/report。初始未校准 checkpoint 可从尚未拟合的状态开始校准；完整训练迭代 checkpoint 必须含已校准状态。旧配置缺少损失语义的 checkpoint 不自动迁移。
- 数据/划分：固定版本G1 LAFAN1，完整40条加载，既有 walk1/dance1 两动作CPU采集，种子0；不新增训练/验证划分，不声称泛化。
- 预算：Mac CPU2环境，默认全宽网络；一次2轮真实训练闭环和一次从该 checkpoint 续1轮；每次上限600秒、整个检查至多20分钟。失败则先修局部实现，不自动启动更长训练或调参扫描。
- 验收：误差单位/顺序正确，四元数反号误差相同，零旋转和近180度值/梯度有限；校准各组贡献在未触底时为1；权重不带梯度、只校准一次；局部梯度数值检查通过；raw模式还原旧loss；checkpoint准确保存/恢复分母与校准来源；真实闭环三阶段均更新对应参数，解析奖励一致，续训没有重新校准。
- 固定不变：采集、参考时间、reward/终止定义、网络、优化器、采样、历史噪声、actor/critic目标及数据范围。本次不叠加其余三个待讨论的设计差异。
- 保存：源文件/依赖/配置/命令/硬件/种子、逐组原始L1和加权贡献、BCE、梯度摘要、校准窗口身份、实际转移和 checkpoint；沿用既有落盘。
- 无效/停止条件：几何误差或梯度非有限、组贡献计算不符、恢复重新校准、误把参考动作当动力学标签、非对应模块更新。触底或极端初始权重会明确报告，不据短跑判定训练质量。
- 下一步：本次只确认方法接入和记录正确。正式比较回报/失败率、选择更具代表性的校准样本或重新调权重，等用户启动训练时另定协议与预算。
