# 预备评测与分析（尚未实现/执行）

用户于2026-10-26决定先保存训练记录和checkpoint，优先试跑训练，以下方案作为后续待办，不放入每轮训练。它们是建议，不是已冻结的正式实验协议或已有结果。

## 机器人跟踪质量

- 固定checkpoint、参考clip、起点、物理参数和噪声条件，在真实mjlab中执行；固定条件基准与随机化稳健性分开。
- 指标候选：整段成功率、首次失败时间、完成比例、关节角误差（度）、身体位置误差（厘米）、身体朝向误差、根部轨迹误差、按完整预定时长归一化的回报。
- 全局根部漂移与锚点相对姿态误差分别报告；存活期间的误差必须和完成率一起看。训练中随机起点/短episode的reward不能直接冒充整段成功率。
- 按每clip、动作类别、subject展开；同时说明clip平均与按帧加权的区别。
- 待确认：先评测训练动作覆盖还是预留动作泛化；目前没有新划分或独立测试集。Mac可以先用短窗口检查评测器，不能把短窗口结果称作整段成功率。

## 世界模型预测质量

- 从保存的真实状态、上下文出发，使用同一串实际执行动作进行开放环自回归；比较1/8/32步的状态、根部/关节/速度误差。
- 不用真实中间状态替换预测。解析FK/奖励一致性不代表学到的动力学准确。
- 记录终止概率与实际failure标签的校准、模型预期回报与真实回报的偏差。
- 论文8步误差的具体定义、单位与本项目state71表示尚需核对，不能直接拿数值横比。
- 保存的kinematic state可以支持模型误差诊断；精确复现原仿真分支还依赖未保存的内部求解器/接触状态。

## 梯度稳定性与动作影响

- 先利用逐轮已有的裁剪前全局梯度norm与encoder/decoder摘要查看趋势；区分模块、动作类别和训练采样难度变化。
- 后续增加固定样本/固定噪声探针，比较梯度方向、裁剪前分布、更新幅度及轨迹时间步/关节的回报敏感度。
- 对少量固定起点做动作方向的正负微扰，用真实仿真局部回报变化与模型预测对照；接触附近检查多个扰动尺度。
- 按walk/run/sprint/dance/jumps/fallAndGetUp/fight等文件类别分析；文件类别不是逐帧动作阶段真值。
- 模型误差、梯度尖峰和失败的共同出现仅是相关证据；对固定条件下更新前后policy做配对评测后，才能讨论该次更新的影响。
- **目前不保存完整参数梯度向量、autograd图、逐帧接触力或额外阶段权重快照。** 想象probe对应actor更新前/critic更新前；周期checkpoint对应整轮更新后。可做新的离线诊断，不能承诺精确重算历史那一次完整BPTT梯度；若以后需要，应先启用专门的阶段快照。

## 执行前仍需确定
